This directory contains supplemental data and source code for the
paper "Magnetic fields with precise quasisymmetry" by Matt Landreman
and Elizabeth Paul.

The "configurations" directory contains VMEC input and output files
for the new quasi-axisymmetric (QA) and new quasi-helically symmetric
(QH) magnetic configurations. The Boozer coordinate data for these
configurations is also available there.

The "calculations" directory contains source code and input/output
files used for the optimization and analysis of these
configurations. Scripts used to produce the figures in the paper can
be found here together with the underlying data.

The "codes" directory contains the SIMSOPT, VMEC, and BOOZ_XFORM codes
at the git commits used for the optimizations and analysis.
